# Week 2 Assignment Workbooks

This folder hosts Jupyter notebooks that implement the Week 2 Sequence Alignment assignment without touching the `submissions/` exercises. Each notebook focuses on one deliverable so they can be executed independently and exported into the Moodle ZIP bundle.

## Notebooks

- `Task1_distances.ipynb` — selects ≥3 Lab 1 sequences, computes Hamming/p-distance, and formats a distance matrix ready for `notes.pdf`.
- `Task2_pairwise_alignments.ipynb` — picks two Lab 1 sequences, runs Biopython global vs local alignments, and captures comparison snippets.
- `Task3_msa_semiglobal.ipynb` — prepares sequences for Clustal Omega, documents conserved motifs, and demonstrates a semiglobal alignment option.

All notebooks assume the Lab 1 FASTA files live under `data/work/<handle>/lab01/`. Run them from the repo root so relative paths stay consistent.

# AI usage
Github Copilot was used in agent mode to do this assignment. All code was reviewed and edited by the student to ensure correctness and understanding.
