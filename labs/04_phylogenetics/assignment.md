# Assignment 4 — Phylogenetics

## Tasks

1. **(3 pts)** Compute a distance matrix for ≥10 sequences (your own multi-FASTA) and save the table.
2. **(4 pts)** Build a Neighbor-Joining tree with Biopython and interpret the resulting clusters.
3. **(3 pts)** Compare your tree with an online MSA (Clustal Omega) and mark conserved regions.
4. **Bonus (+1 pt)**: add a graphical visualization of the tree (using `matplotlib` or `ete3`, if available).
