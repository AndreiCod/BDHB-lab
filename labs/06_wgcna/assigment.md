Exploring Co-Expression Networks in TP53-Associated Data
Objective:
Using the RNA-Seq dataset from Lab 3, construct, visualize, and interpret a gene co-expression network, focusing on TP53-related samples. This assignment deepens your understanding of gene interactions in cancer biology, connecting to prior work with TP53-associated data.

Assignment Tasks:
Dataset Preparation:

Use the RNA-Seq dataset from Lab 3, selecting TP53-associated samples.
Preprocess data: normalize values (e.g., log-transformation) and filter low-variance genes.
Network Construction:

Calculate pairwise correlations (e.g., Pearson correlation) to build an adjacency matrix.
Apply a threshold or weighted adjacency to construct the network.
Module Detection:

Identify modules using WGCNA.
Assign module labels and highlight hub genes in at least one module.
Visualization:

Visualize the network using Cytoscape, NetworkX, or Gephi.
Color-code nodes by module and annotate hub genes.
Biological Interpretation:

Perform functional enrichment analysis on one module using tools like DAVID or  KEGG
Discuss how the module’s biological functions relate to TP53’s role in cancer.
Deliverables:
Report:

Briefly explain methods and steps.
Include network visualizations, module descriptions, and functional interpretations.
Code:

Submit scripts or notebooks for preprocessing, network construction, and visualization.
Reflection:

Summarize challenges and insights in one paragraph.
